# 安全网络加密网盘系统（Cloud Storage）

> 本项目实现了一个基于安全认证、加密传输和加密存储的网络加密磁盘系统，支持用户安全登录、文件上传下载、用户组隔离、多用户并发访问等功能。

---

## 🔐 功能概览

1. **用户登录与认证**  
   - 支持用户名 + 密码登录  
   - 密码通过 SHA-256 哈希存储  
   - 可扩展多种登录方式（短信、Email、数字证书、微信/支付宝）

2. **会话与密钥管理**  
   - 每次登录生成一次性会话密钥  
   - 支持用户组密钥，实现多用户共享安全存储  
   - 文件上传/下载全程加密传输（XOR + 会话密钥示例实现）

3. **文件加密与完整性保护**  
   - 本地存储加密文件，服务器无法直接解密  
   - 文件上传下载支持 SHA-256 完整性校验  
   - 防篡改、防中间人攻击

4. **多用户与用户组支持**  
   - 用户组隔离，每个用户组有独立存储空间  
   - 用户组内可多终端登录、共享文件  
   - 支持多用户同时连接、日志实时输出

5. **操作界面**  
   - 暂时只支持终端操作

---

## ⚙️ 使用说明

### 1. 环境要求

- Python 3.8 及以上  
- Windows / Linux / macOS  
- 无需依赖第三方加密库（示例中使用 Python 内置 `hashlib`、`secrets`、`socket`）

### 2. 运行步骤

1. 打开终端，进入项目目录：
   ```bash
   cd "D:\桌面文件\cloud storage"
启动服务器：

python server.py


启动客户端：

python client.py


按提示输入：

用户名、密码

文件路径上传 / 文件名下载

用户组名称

文件会加密上传到服务器，本地和服务器端进行完整性校验。

📂 项目结构
cloud-storage/
│
├── client.py        # 客户端程序
├── server.py        # 服务器程序
├── users.txt        # 用户数据库（用户名:哈希:用户组）
├── storage/         # 存储加密文件
├── key_*.bin        # 会话/用户组密钥文件（生成后）
└── README.md        # 项目说明文件

🔧 注意事项

不要上传真实密码，users.txt 中应只保存密码哈希

本示例加密算法为 XOR，适合实验演示，可扩展为 AES / ChaCha20 等安全算法
